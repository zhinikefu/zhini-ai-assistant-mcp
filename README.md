# 知你AI助手 MCP｜多平台账号客户数据与聊天记录连接器

[知你AI助手官网](https://ai.zhinikefu.com/?f=github) · [知你客服官网](https://zhinikefu.com/?f=github) · MCP 服务地址：`https://mcp.h5bqb.top/mcp`

## 产品介绍

知你AI助手是一项面向 AI 工具的多平台客户沟通数据连接服务。把你的平台账号接入知你AI助手后，可通过 Streamable HTTP MCP，将这些账号上的客户资料、标签、负责人、当前会话、历史会话和聊天记录连接到 AI 工具，不需要在多个平台后台之间来回切换。

团队可以直接用自然语言查找客户、了解沟通前情、检索退款或投诉记录、筛选目标客户、发现购买意向，并基于完整消息上下文整理业务结论；需要维护资料或触达客户时，AI 在用户明确确认后修改客户姓名/备注名/电话/描述、批量添加或移除客户标签、批量打开选定对话、异步发送文本或图片消息并跟踪发送进度。查询与操作范围由当前凭据权限决定，结果可以继续追溯到相关客户、会话和原始消息。

服务支持两种认证方式：**MCP 原生 OAuth 2.1**（浏览器授权，无需 API Key，含动态客户端注册与 PKCE，授权可随时在官网吊销）或 **静态 Bearer API Key**。

## 核心能力

1. **多平台账号客户数据统一查询**：查询个微、企微、公众号、小程序、视频号、微信客服、抖音、小红书、微博、微信小游戏、微信小店、网站/H5 客服等平台账号的客户资料、标签与会话数据。
2. **当前客服会话分诊**：查看各平台账号的待接待、我的会话、同事会话和 AI 会话。
3. **客户资料与沟通前情查询**：按姓名、手机号、微信号、平台账号、渠道、客服、负责人、标签或时间，定位跨平台客户。
4. **客户画像信息整理**：查询客户的资料、标签、来源渠道、负责人和联系信息。
5. **历史会话与聊天记录检索**：检索各平台账号的历史会话与客服聊天记录。
6. **消息关键词与时间查询**：按退款、投诉、报价、试用、购买等消息关键词和发生时间，定位相关客户会话。
7. **完整消息上下文读取**：将 AI 整理结果追溯到对应平台渠道、客户、会话和原始消息。
8. **渠道与业务字典查询**：查询平台账号、渠道、客服和标签字典。
9. **API Key 用量查询**：查询当前 API Key 的总额度、已使用量和剩余额度。
10. **客户资料维护**：在用户明确确认后修改客户姓名、备注名、电话或描述；未传字段保持不变，空字符串表示清空。
11. **客户标签管理**：为 1-20 个客户批量添加 1-10 个现有标签，或为单个客户移除最多 10 个标签；只操作客户身上的标签，不删除标签定义。
12. **客户触达与消息发送**：在用户明确确认后，批量打开选定客户对话（每次最多 20 个），创建最多 100 个 UID、最多 2 条文本/图片消息的异步群发任务，并跟踪发送进度、查询和管理历史任务。

## 使用方法

### 1. 连接 MCP（两种认证方式二选一）

**方式一：OAuth 2.1 浏览器授权（推荐）**——不配置任何静态认证字段，客户端首次访问时按服务端 OAuth 挑战打开浏览器完成知你账号授权：

```json
{
  "mcpServers": {
    "zhini": {
      "type": "http",
      "url": "https://mcp.h5bqb.top/mcp"
    }
  }
}
```

**方式二：静态 API Key**——访问[知你AI助手官网](https://ai.zhinikefu.com/?f=github)，注册或登录后创建 API Key：

```json
{
  "mcpServers": {
    "zhini": {
      "type": "http",
      "url": "https://mcp.h5bqb.top/mcp",
      "headers": {
        "Authorization": "Bearer ${ZHINI_API_KEY}"
      }
    }
  }
}
```

环境变量：

```text
ZHINI_API_KEY=YOUR_API_KEY
```

### 2. 用自然语言查询与触达

- 现在有哪些客户正在等待接待？
- 查一下这个客户最近聊了什么，还有哪些事情待确认？
- 找出近 7 天提到退款的历史会话。
- 哪些客户最近提过报价、试用或购买？
- 把这些已选客户的对话打开到我的对话。
- 把这位客户的电话改成 13800000000，描述清空。
- 给确认好的这批客户打上“已回访”标签，或把某个客户的旧标签去掉。
- 向已确认的客户批量发送跟进文本或图片，发完告诉我进度。
- 整理最近登录异常反馈的共同问题。

## 适用业务需求

- **查客户与画像**：按姓名、手机号、微信号、平台账号、渠道、客服、标签或时间定位客户，读取资料与画像。
- **查聊天记录与历史会话**：按关键词与时间召回历史会话，读取完整消息上下文。
- **回复前了解前情**：客户资料、最近会话和往来消息关联查看，换人接待也能快速接手。
- **找高意向客户**：从真实对话识别购买、试用、升级、续费意向，输出跟进名单与原话依据。
- **查投诉退款风险**：定位退款、投诉、负面反馈会话，整理证据与典型样本。
- **客户分群**：按平台、渠道、客服、标签、联系人类型与时间组合筛选，圈定跟进名单。
- **客户资料与标签维护**：确认后修改客户姓名/备注名/电话/描述，批量添加或移除客户标签。
- **主动触达**：确认后批量打开对话、发送文本或图片消息，跟踪发送进度与历史任务。
- **多平台对比与反馈归纳**：按平台账号、渠道、客服、时间比较沟通情况，归纳共性问题与需求趋势。

## 数据与权限说明

- 查询能力保持只读；客户资料修改、客户标签管理、批量打开对话与消息发送均为受控操作，仅在用户明确确认后执行。客户资料只开放姓名、备注名、电话、描述；标签只操作客户身上的现有标签，不删除标签定义或标签分组；不接待、转接或关闭会话。

- 查询结果受当前凭据对应的数据权限约束；OAuth 授权可随时在官网吊销。
- API Key 应保存在客户端环境变量或安全配置中。
